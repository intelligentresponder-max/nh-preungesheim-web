# Schriften (lokal, DSGVO)

Die Seite bindet **keine** Schriften von fremden Servern ein.
Bitte hier ablegen (beide Schriften stehen unter der SIL Open Font License):

- `Fraunces.woff2` – Überschriften
- `AtkinsonHyperlegible-Regular.woff2` – Fließtext

Solange die Dateien fehlen, nutzt die Seite die Systemschrift (Fallback in `css/style.css`). Das ist gewollt und funktioniert.
