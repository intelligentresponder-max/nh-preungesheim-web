# Schriften (lokal, DSGVO)

Die Seite bindet **keine** Schriften von fremden Servern ein. Die Dateien liegen hier:

- `Fraunces.woff2` – Überschriften (variabel, Gewicht 100–900, Teilsatz „latin“)
- `AtkinsonHyperlegible-Regular.woff2` und `-Bold.woff2` – Fließtext (Teilsatz „latin“)
- `LICENSE-*.txt` – Lizenztexte (SIL Open Font License 1.1)

Herkunft: npm-Pakete `@fontsource-variable/fraunces` und `@fontsource/atkinson-hyperlegible` (Version 5.3.0, November 2026).
Der Teilsatz „latin“ deckt Deutsch ab (ä ö ü ß, „ “, €). Andere Alphabete (z. B. Kyrillisch) fielen auf die Systemschrift zurück.
